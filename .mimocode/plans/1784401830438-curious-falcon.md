# План: Компактные кнопки шаблонов и улучшение верстки UI

## Проблема
Кнопки шаблонов занимают всю ширину сайдбара (380px), что выглядит громоздко и перегружает интерфейс.

## Решение
1. Уменьшить ширину кнопок шаблонов до ~180px (половина ширины сайдбара)
2. Расположить кнопки в 2 колонки для экономии вертикального пространства
3. Уменьшить высоту кнопок с 18px до 16px для большей компактности
4. Скорректировать вертикальные отступы между элементами UI
