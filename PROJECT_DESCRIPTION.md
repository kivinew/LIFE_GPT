# LIFE_GPT - Симуляция эволюции клеток
# ------------------------------------------------------------------------
# Проект представляет собой интерактивную визуализацию процесса эволюции в условиях ограниченных ресурсов.
# В игре участвуют различные типы клеток, которые борются за выживание, размножение и доминирование в антропогенной среде.
# Simulation of cellular evolution in an artificial ecosystem with resource competition
# ------------------------------------------------------------------------
#
# Проект LIFE_GPT (Life Game Python) представляет собой:
#
# 1. Полноценная игра-симулятор, в которой игрок может создавать, модифицировать и эволюционировать клетки
#    для достижения Dominance в ограниченном мире с дефицитом ресурсов.
#
# 2. Демонстрация принципов эволюции: наследственность, мутации, отбор, кооперация и агрессия.
#
# 3. Интерактивный образовательный инструмент, показывающий динамику популяции, динамику ресурсов
#    и взаимосвязь между морфологическими, поведенческими и социальными特征ами.
#
# ------------------------------------------------------------------------
#
# Игра была разработана на основе идей игры Conway's Game of Life, но с существенными улучшениями:
# - Реалистичные физические законы (инерция, трение, метаболизм)
# - Генетическая инженерия (наследование и мутации генов)
# - Комплексная экосистема (ресурсные поля, hotspots)
# - Игровой интерфейс для исследования и манипуляции

# ------------------------------------------------------------------------
# 1. КАРТА СИТУАЦИИ И ЦЕЛИ
# ------------------------------------------------------------------------
#
# Игра происходит в 2D-midworld'е размером 1200x700 пикселей с правой боковой панелью (SB=300)
# для пользовательского интерфейса. Миром управляет сторона, предоставляющая ресурсы (ресурсное поле)
# и генерирующая еду для фототрофов.
#
# Центральная зона (0 <= x < 900, 0 <= y < 700) - игровая область
# Боковая панель (900 <= x < 1200, 0 <= y < 700) - пользовательский интерфейс

# ------------------------------------------------------------------------
# 2. ОСНОВНЫЕ ТИПЫ КЛЕТОК
# ------------------------------------------------------------------------
#
# В игре используются три основных типа клеток, каждый со своими стратегиями выживания:
#
# 1. ФИТОТРОФЫ (PHOT = 0)
#    - Питательные клетки, которые питаются только из ресурсного поля (фотосинтез)
#    - Медленно движутся, имеют высокую эффективность поглощения пищи
#    - Уделяют приоритет исследованию территории и избеганию угроз
#    - Примеры: Растения, водоросли, бактерии-фиксаторы углерода
#
# 2. ЗООФАГИ (ZOOP = 1) - Хищники
#    - Pure predators, охотятся исключительно на клетки других типов
#    - Быстро движутся, имеют эффективную систему нападения
#    - Имеют сложную систему реагирования на атаки старших/младших особей
#    - Примеры: Волки, гепарды, хищные рыбы
#
# 3. ПОЛИФАГИ (POLY = 2)
#    - Универсальные организмы, могут питаться как из поля, так и охотиться
#    - Сбалансированные мобильность и выносливость
#    - Кооперативное поведение для социального преимущества
#    - Примеры: Всеядные животные,omnivorus насекомые

# ------------------------------------------------------------------------
# 3. СОЦИАЛЬНАЯ БИОЛОГИЯ И ВЗАИМОДЕЙСТВИЯ
# ------------------------------------------------------------------------
#
# Клеточные взаимодействия поражают сложной системой социальных стратегий:
#
# 1. PASS (Пассивные) - Игнорируют другие классы
#    - Прекрасно работают в моноспецифических популяциях
#    - Спокойно существуют рядом с другими клетками
#    - Примеры: Бактерии, эффективно создающие биопленки
#
# 2. AGGR (Агрессивные) - Крадут энергию у более слабых клеток других классов
#    - Используют стратегию "украсть до того, как украдут у тебя"
#    - Могут проводить расчеты вероятности и планировать атаки
#    - Примеры: Хищные птицы, хищные млекопитающие
#
# 3. COOP (Кооперативные) - Делятся энергией с нуждающимися
#    - Нас saving энергии на одного, но обладают коллективной защитой
#    - Обеспечивают выживание в условиях ограниченных ресурсов
#    - Примеры: Рабочие муравьи, sociaux gregarious mammals

# ------------------------------------------------------------------------
# 4. ГЕНЕТИКА И НАСЛЕДСТВО
# ------------------------------------------------------------------------
#
# Каждая клетка имеет геном, содержащий 8 генов:
#
# - speed (Скорость): Скорость передвижения (0.5-4.0)
# - sense (Дальность чувств): Радиус обнаружения объектов (10-120)
# - mass (Масса): Размер и вес клетки (2-8)
# - metabolism (Метаболизм): Базовый расход энергии (0.01-0.1)
# - mut_rate (Частота мутаций): Вероятность мутации при репликации (0.01-0.3)
# - diet (Тип питания): PHOT/Zoop/POLY (0/1/2)
# - interact (Социальная стратегия): PASS/AGGR/COOP (0/1/2)
# - divide_chance (Шанс размножения): Вероятность деления вместо роста (0.1-0.9)
#
# Когда клетка делится, ее геном клонируется с возможными мутациями:
# - Каждый ген имеет шанс мутировать (mut_rate) и изменить значение на +/-15%
# - Мутированные значения обрезаются до допустимых диапазонов
# - Диаметральные и социальные признаки наследуются без мутаций
#
# У.genea�ических вариаций напрямую влияют на класс клетки (CLS), что определяет
# ее принадлежность к определенному видовому типу и типу питания.

# ------------------------------------------------------------------------
# 5. ФИЗИЧЕСКИЕ ЗАКОНЫ И ПОТРЕБНОСТИ
# ------------------------------------------------------------------------
#
# Клетки должны удовлетворять фундаментальным биологическим потребностям:
#
# 1. ПИТАНИЕ (ЭНЕРГИЯ)
#    - Клетки тратят энергию за счет метаболизма, скорости и массы
#    - Эффективность питания зависит от типа клетки и массы
#    - Поглощенная энергия конвертируется с учетом эффективности типа питания
#
# 2. ДВИЖЕНИЕ
#    - Клетки используют инерцию (перенос предыдущего направления)
#    - Сила движения зависит от скорости и времени шагай
#    - Граничные условия предотвращают выход за пределы игрового мира
#
# 3. РАСТЕНИЕ И РАЗМНОЖЕНИЕ
#    - Клетки растут за счет накопленной энергии (размножение)
#    - Увеличение массы при нехватке энергии (жизненная необходимость)
#    - Размножение требует достаточного количества энергии (95% от максимума)
#
# 4. ОГРАНИЧЕНИЕ ЭНЕРГИИ
#    - Максимальный уровень энергии зависит от массы (мас² * 5.5)
#    - Баланс уровня энергии определяет уровень развития и репродуктивную активность

# ------------------------------------------------------------------------
# 6. ИНТЕРАКЦИЯ С МИРОМ
# ------------------------------------------------------------------------
#
# Ресурсное поле обеспечивает основу жизни игры, предоставляя основную пищу:

# 1. РЕГЕНЕРАЦИЯ

#    - Медленное диффузирование между соседними ячейками

#
# 2. ПОГЛОЩЕНИЕ
#    - Клетки потребляют энергию из области (0.15 * dt)
#    - Multipliers hotspots и мертвых клеток увеличивают поглощенную энергию

#
# 3. МЁРТВЫЕ КЛЕТКИ КАК ИСТОЧНИКИ
